# Hospital Analytics Dashboard

An End-to-End Data Analytics project developed using **Python, MySQL, Microsoft Excel, and Microsoft Power BI** to analyze hospital data and generate meaningful healthcare insights. The project demonstrates the complete analytics workflow, including data cleaning, SQL analysis, KPI generation, dashboard creation, and business reporting.

---

## Project Overview

Hospitals generate a large volume of patient data every day, including admission details, department information, waiting times, billing records, emergency cases, and patient satisfaction levels. Analyzing this data manually is time-consuming and may delay decision-making. This project transforms raw hospital data into meaningful business insights through interactive dashboards that support operational efficiency and data-driven healthcare management.

---

## Objectives

- Clean and preprocess hospital data using Python.
- Perform business analysis using SQL.
- Generate key healthcare KPIs.
- Build an Excel dashboard for reporting.
- Create an interactive Power BI dashboard.
- Support data-driven decision-making in hospital management.

## Project Workflow

1. Collected the hospital dataset from Kaggle.
2. Cleaned and transformed the raw data using Python.
3. Handled missing values and standardized important columns.
4. Performed business analysis using SQL queries.
5. Built KPI reports and Pivot Dashboards in Microsoft Excel.
6. Developed an interactive dashboard in Microsoft Power BI.
7. Documented the complete project with business insights.
